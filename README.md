# 408：知识大陆 · Android 更新

此仓库只公开 Android 试玩版 APK、`latest.json` 和版本说明，不包含应用源码或个人题库。

手机安装 v0.4.0 后，可在应用内进入“更新”页检查、下载并覆盖安装后续版本。首次从 v0.3.0 或更早版本升级到 v0.4.0，仍需手动安装一次，因为旧版尚无更新页。请勿先卸载应用，否则本地题库与进度会丢失。

发布时把新 APK 覆盖为 `knowledge408.apk`，计算其 SHA-256 和字节数，递增 `latest.json` 的 `version_name` 与 `version_code`，并在同一次 Git 提交中推送。APK 必须沿用相同签名。当前 APK 使用调试签名，仅供个人试玩。
