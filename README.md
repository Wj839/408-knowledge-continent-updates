# 408：知识大陆 · Android 更新

此仓库仅公开 Android 试玩版 APK 和版本说明，不包含应用源码或个人题库。

在手机应用内进入“更新”页即可检查最新 Release、下载安装包，并由 Android 系统确认覆盖安装。

首次从 v0.3.0 或更早版本升级到 v0.4.0，需要手动安装一次 v0.4.0，因为旧版尚无应用内更新页。请勿先卸载应用，否则本地题库与进度会丢失。

发布资产文件名固定为 `knowledge408.apk`。发布者须递增版本号和 `versionCode`，并沿用同一 APK 签名；本仓库当前 APK 使用调试签名，仅供个人试玩。正式发布应改用长期保管的正式签名。
